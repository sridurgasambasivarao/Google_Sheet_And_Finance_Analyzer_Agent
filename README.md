Connection to Google Sheets: The agent interfaces with Google Sheets to fetch the relevant data. It successfully connects and authenticates with your Google Drive and Sheets.

Data Analysis: Using the Yahoo Finance MCP server (Market Capitalization Price), the agent can analyze the data present in your Google Sheets. This allows you to pull in financial data, analyze trends, and gain insights.

Report Generation: Once the necessary data is collected, the agent can generate detailed PDF reports. Users can ask various finance-related questions, and the agent will use the data from your Google Sheets or from Yahoo Finance as needed to create comprehensive reports.

Updating Data: The agent can also update your Google Sheets with new data, ensuring that you have the latest financial information.
